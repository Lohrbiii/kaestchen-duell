▦ Kästchen-Duell

Ziehe Striche, schließe Kästchen und sammle Punkte. Online spielst du über einen Raumcode.

Für Online-Partien müssen beide Spieler diese HTML-Datei über eine Website mit HTTPS öffnen (z. B. GitHub Pages). Die Verbindung nutzt PeerJS als Vermittlungsdienst; der Host muss während des Spiels online bleiben.
